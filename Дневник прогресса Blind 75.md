# Дневник прогресса — NeetCode Blind 75

[CodeRun — основной маршрут](<Дневник прогресса.md>) · [Blind 75 на NeetCode](https://neetcode.io/practice/practice/blind75)

Отдельный трек для 75 задач NeetCode. Он не заменяет маршрут CodeRun: CodeRun закрепляет базу, а Blind 75 тренирует узнавание интервью-паттернов.

**Как вести статус:**

- **Не начата** — попыток ещё не было.
- **В процессе** — самостоятельная попытка начата, решения пока нет.
- **Решено локально** — код прошёл локальные примеры; принятие платформой указывай отдельно в заметке.
- **Принято** — решение принято NeetCode/LeetCode.
- **Повторить** — `да`, пока задачу нельзя уверенно решить заново без подсказки.
- **Степень помощи** — `нет / справка / намёк / разбор / парное кодирование`. После помощи не повышай решение задним числом до самостоятельного.
- В **заметке** фиксируй сложность для тебя, ошибку, паттерн и результат отправки. При повторном решении обновляй ту же строку.

**Старт на 15.10.2026:** разобраны две задачи. Обе пока считаются учебными локальными решениями, а не самостоятельным зачётом.
