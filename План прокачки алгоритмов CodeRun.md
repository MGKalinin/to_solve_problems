# План прокачки алгоритмов CodeRun

**Цель:** самостоятельно решать задачи на Python. Алгоритмы — дополнительная практика к основному обучению ML-инженерии.
**Ритм:** 2–3 занятия по 45–60 минут в неделю, по силам.
**Под рукой:** [Дневник прогресса](<Дневник прогресса.md>) · [Шаблоны и источники](<Шаблоны.md>).

## Как заниматься

1. **Новая тема:** изучи объяснение, пройди пример, напиши решение с закрытым источником. Учебник и LLM разрешены.
2. **Знакомая тема:** 25–40 минут пробуй сам; если продвигаешься — до 60. Код, перебор и отладка разрешены с начала.
3. **Застрял:** запиши, что не получается → возьми намёк → при необходимости разбор. Отметь помощь, затем реализуй сам. Устал — продолжи в следующее занятие.
4. **Решил:** отправь в CodeRun, запиши результат и время. Справку Python отмечай отдельно от подсказки алгоритма.
5. **Повтор:** при затруднениях вернись через 3–7 дней; затем попробуй новую задачу на тот же приём. Обязательных трёх кругов нет; исправленный самостоятельно баг не обнуляет успех.
6. **Проверка:** по желанию вместо обычного занятия — 2–3 незнакомые задачи за 60–90 минут без помощи. Разбор после таймера.

## Куда двигаться

**Темы:** массивы и строки → словари и множества → сортировка → префиксы → два указателя → бинпоиск → стек/очередь → DFS/BFS и деревья → простая динамика. Дейкстра и DSU — позже по потребности.

**Сейчас, «Быстрый старт»:** №11 → №12 → №15 → №20 → №17. №18 — после изучения обхода графа. Решённое не начинаем заново.

Иди внутри выбранной подборки; слишком сложную задачу можно отложить. Не нужно закрывать всё для перехода дальше. Раз в две недели смотри, удаётся ли самостоятельно применять изученное в новых задачах и хватает ли времени на ML.
